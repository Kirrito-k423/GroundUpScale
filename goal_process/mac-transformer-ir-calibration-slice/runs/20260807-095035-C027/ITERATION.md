# C027：环境门禁 v2 的可检验语义

- **开始：** 2026-08-07T09:50:35+08:00
- **阶段：** M5 / IMPLEMENT
- **动作类型：** IMPLEMENT
- **关联验收/未知量：** AC-06、AC-07、AC-08、H-02、H-03

## 预注册

- **本轮 micro-goal：** 在不放宽原有实验噪声与误差合同的前提下，把本机环境资格从易受瞬时 UI 单进程峰值影响的 v1，升级为可复现、可解释、按整机容量归一化的 v2。
- **当前假设：** “所有竞争进程在采样窗口中的总 CPU / 逻辑 CPU 总容量”能区分持续的 board/媒体计算与普通短时 UI 活动；10 核机器上总竞争占用上限 `0.10` 会拒绝此前约 150%–200% 单核口径的 board 负载，同时允许一次约 50% 单核口径的 UI 活动。
- **已有证据：** C020 证明环境必须前置门禁；C025 证明停下 board 后可达到合格窗口；C026 证明 v1 的 25% 单进程峰值规则产生不同 UI 进程触发的瞬时误拒。
- **证据等级：** E2。
- **唯一主要变量：** 环境竞争 CPU 判据从“单个进程采样峰值 ≤25% 单核口径”改为“每个采样窗口全部竞争进程总和的最大值 / (`100 * logical_cpu_count`) ≤0.10”。平台、AC 电源、thermal nominal、归一化 1 分钟 load≤0.25 和 fail-closed 原则不变。
- **公共可观察 seam：** `evaluate_environment_validity` 的 check/policy 输出、`collect_environment_validity` 的原始采样、Run Manifest 的 `hardware_cohort`。
- **预期观察：** 低整机总竞争占用即使单进程瞬时达到 50.3% 也 PASS；持续总竞争占用超过 10% 整机容量 FAIL；缺少总量采样时 fail closed；Run Bundle cohort 包含 `local-apple-silicon-v2`。
- **判别规则：** 每个行为先出现针对公共 seam 的失败测试再实现；目标测试与全量测试通过；真实 preflight 报告的公式、原始样本和判定一致。任何用睡眠或提高单进程阈值规避问题的实现均不接受。
- **成本与风险：** 预计 10–20 分钟，无付费资源。风险是进程枚举误差或短生命周期进程遗漏；用原始每窗口总量、top 进程诊断和 fail-closed 状态保留可审计性。
- **停止与回滚：** v2 若不能在测试与真实 preflight 上同时成立，则不运行 benchmark，恢复 board 服务并保留 v1 历史证据；不修改 3%/5 次/5% 合同。
